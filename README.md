# aMule Ricerca

App Android (solo ricerca) che si collega ad aMule per Linux/Docker tramite il protocollo EC (External Connections).

Impostazioni (menu ⋮ > Impostazioni): IP LAN, porta EC (default 4712), password delle connessioni esterne.
In aMule: Preferenze > Controllo remoto > "Accetta connessioni esterne". Se aMule gira in Docker la porta 4712 deve essere pubblicata.

APK: GitHub > Actions > Build APK > artifact `AmuleSearch-debug`.
